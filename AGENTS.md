# NetLabs — инструкции для ИИ-агентов

Этот файл обеспечивает автоматическое обнаружение правил агентами из корня репозитория.

**Перед работой обязательно прочитайте:**
- [Полные правила](.agents/RULES.md) — режимы Documentation / Implementation / Validation, ограничения изменений и техническая корректность.
- [Стандарт лабораторий](.agents/standards/LAB-STANDARD.md) — структура EVE-NG/GNS3, документация и критерии проверки.

**Ключевые требования:**
- Если задача — только оформление, не изменять конфигурации, топологии и проектные файлы `.cfg`, `.unl`, `.gns3`.
- Для новых и изменяемых лабораторий проверять конфигурации, ссылки, startup-config и соответствие узлов.
- Не утверждать, что лаборатория успешно запущена, если выполнена только статическая проверка.
- Документация, задания и сценарии — на русском языке; CLI и технические обозначения сохранять в оригинале.
- Использовать существующие [skills](.agents/skills/) и [шаблоны](.agents/templates/); не дублировать правила.
- Запуск общего валидатора из корня: `python3 .agents/tools/validate_netlabs.py --all`.

Дополнительные инструменты, тесты, шаблоны и стандарты находятся в `.agents/`. Самостоятельно не изменять пользовательские лаборатории ради реорганизации служебных файлов.
