# IGP — лаборатории EVE-NG

Каталог лабораторных работ по **внутренним протоколам маршрутизации** (Interior Gateway Protocols): OSPF, IS-IS и другим. Каждая лаборатория размещается в отдельной папке соответствующего протокола.

## Каталог лабораторий

| Протокол | Лаборатория | Содержание |
|---|---|---|
| OSPF | [OSPF Multiarea (topology 1)](OSPF/OSPF%20Multiarea%20%28topology%201%29/) | Многообластная OSPF-топология EVE-NG, файл `.unl`, конфигурации устройств и PNG-схема |

Другие лаборатории (например, **IS-IS**) будут добавляться по мере готовности. Сейчас в EVE-NG-разделе IGP представлена лаборатория OSPF.

**Быстрый старт:** [файл топологии EVE-NG](OSPF/OSPF%20Multiarea%20%28topology%201%29/ospf_multiarea.unl) · [схема топологии](OSPF/OSPF%20Multiarea%20%28topology%201%29/Topology.png).

Импортируйте `.unl` в EVE-NG, проверьте совместимость образов и примените конфигурации из каталога лаборатории, если они не загрузились автоматически.
